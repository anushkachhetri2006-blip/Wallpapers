#  Wallpapers

A beginner-friendly HTML mini-project that showcases a collection of cute wallpapers organized into different categories.

##  Categories

*  Cartoon Edition
*  Shinchan Edition
*  Spiderman Edition
* Stitch Edition

##  Features

* Categorized wallpaper collections
* Images displayed in a simple gallery layout
* External reference links for each wallpaper
* Simple and beginner-friendly HTML structure

##  Technologies Used

* HTML5

##  Purpose

This project was created as a beginner HTML project to practice basic web development concepts such as headings, images, hyperlinks, `<div>` elements, attributes, and basic inline styling.
